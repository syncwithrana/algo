🧩 I. Easy Level — Basic String Manipulations
These check your comfort with raw character arrays, pointers, and basic operations.
Reverse a string (in place, without using library functions).
Check if a string is palindrome.
Implement strlen, strcpy, strcmp, strstr.
Count vowels, consonants, digits, and spaces in a string.
Find the frequency of each character in a string (ASCII-based count array).
Remove duplicate characters from a string.
Check if two strings are anagrams.
Toggle case of each character.
Find the first non-repeating character.
Check if all characters in a string are unique (using bitmask).
⚙️ II. Medium Level — Sliding Window, Hashing, Prefix Ideas
Now questions need efficiency and substructure recognition.


Longest substring without repeating characters.
Longest palindromic substring.
Count occurrences of a substring in another string.
Find smallest window containing all characters of another string.
Check if a string is rotation of another string.
Group all anagrams from a list of strings.
Find all permutations of a string.
Check if two strings are one edit distance apart.
Implement wildcard pattern matching (? and * support).
Find the longest common prefix among a list of strings.
🧠 III. Hard Level — DP, KMP, Suffix, Trie, and Advanced Patterns
These test algorithmic and pattern matching techniques.
Implement KMP (Knuth-Morris-Pratt) pattern matching algorithm.
Implement Rabin-Karp for substring search (rolling hash).
Longest common subsequence (LCS) of two strings.
Edit distance (Levenshtein distance).
Longest repeating subsequence.
Count distinct substrings using suffix trie/suffix array.
Longest palindromic subsequence.
Minimum insertions to make a string palindrome.
Find all palindromic substrings (expand around center).
Word break problem (DP with dictionary).
🔍 IV. Interview-Style Challenge Mix
These are often asked as final-round challenges.
Given two strings s and t, find the minimum window substring of s containing all chars of t.
Given a string, return all valid IP addresses that can be formed.
Given a compressed string like "a2b3c1", expand it to "aabbbc".
Given a sentence, reverse the order of words.
Given a string, find the lexicographically smallest rotation.
Given string s, find all substrings that are palindromes and return the count.
Given strings A and B, find if A is a subsequence of B.
Find longest common substring (not subsequence).
Given n strings, find the pair with maximum common prefix.
Implement Z-algorithm for pattern search.
💡 Bonus — for Embedded / Systems-Oriented Roles
These test low-level thinking:
Write your own itoa, atoi, and strtok.
Parse a hex or binary string to integer.
Reverse only words, not characters.
Handle NULL termination errors gracefully.
Write a memory-efficient substring search function (without extra arrays).
